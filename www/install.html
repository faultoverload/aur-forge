aur-forge — install instructions

Add this AUR package repo to an Arch Linux client. The repo name is aur-forge by default (override with the REPO_NAME env var in the container).

1. Import the signing key

The GPG fingerprint is shown on the repo's main page. Two equivalent options:

# Option A — fetch from a keyserver using the fingerprint
sudo pacman-key --recv-keys <FPR>
sudo pacman-key --lsign-key <FPR>

# Option B — fetch directly from the repo (works without keyserver access)
curl -fsSL https://aur-forge.gateslab.win/keys/aur-forge.pub \
    | sudo pacman-key --add -
sudo pacman-key --lsign-key "$(curl -fsSL https://aur-forge.gateslab.win/keys/aur-forge.pub | gpg --with-colons --import-options show-only --import | awk -F: '/^fpr:/ {print $10; exit}')"

2. Register the repo

curl -fsSL https://aur-forge.gateslab.win/install-repo.sh | sudo bash

This drops a pacman config snippet at /etc/pacman.d/aur-forge and adds the server to pacman.conf. Read the script before piping to bash if you prefer to inspect:

curl -fsSL https://aur-forge.gateslab.win/install-repo.sh
# review, then:
sudo bash install-repo.sh

3. Install

sudo pacman -Syu
pacman -Ss aur-forge   # list available packages
sudo pacman -S <package-name>
